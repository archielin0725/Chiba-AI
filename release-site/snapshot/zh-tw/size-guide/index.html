兒童的掌圍與手指長度比例不同，手指通常較短、手掌較寬，因此兒童尺寸不能直接套用成人尺寸。年齡也可作為輔助參考：年齡的一半約等於手套尺寸，但每個孩子的手型不同，這只是一項概略指引。

成人的掌圍通常與其他手部尺寸成正比。以上尺寸僅供參考，因為手套會依使用功能採用不同版型：自行車手套使用彈性材質並貼合手部；滑雪手套為保暖而加入能留住空氣的隔熱結構，因此通常需要選擇較大、較寬鬆的尺寸。

介於兩個尺寸之間？

通常建議選擇較大的尺寸。若仍不確定，請將掌圍與產品名稱寄給客服確認。
